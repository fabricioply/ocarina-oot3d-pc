# Ocarina microphone mod — Ocarina of Time 3D (PC port, TriAevum)

Play, hum or whistle an ocarina song into your microphone and the game plays it.

This is a mod for the **native PC port of *The Legend of Zelda: Ocarina of Time 3D*** —
[TriAevum — Echoes of Time](https://github.com/coccofresco/TriAevum) (an AOT recompilation of the 3DS game).
It does **not** work with 3DS emulators or other ports. For a real Nintendo 3DS there is a sibling project:
[ocarina-3ds](https://github.com/fabricioply/ocarina-3ds).

> Fan project, not affiliated with Nintendo, Grezzo or the TriAevum project. **No game, ROM or data extracted from
> the game is distributed here.** You need your own legally obtained copy of the game, already set up in TriAevum.

[Leia em português](README.pt-BR.md)

## What it does

- While the ocarina is open ("play freely" mode), it listens to your microphone and detects the notes.
- If the phrase clearly matches one of the **12 songs**, the game plays it by itself (the same way a controller
  would).
- If it is unsure (e.g. *Saria's Song* vs *Song of Storms*), the game's **own native Yes/No text box** asks
  "<song>?", one candidate at a time. Nothing is drawn outside the game.
- The microphone is chosen **inside the game**: press **Esc** → tab **Microfone da Ocarina**. You can switch
  devices live, see the input level and the last detected note.
- Assisted mode: the phrase only has to be *similar*; you can transpose it to any key (the interval shape matters).

The mod only plays the commands: the game still applies its normal rules (right place, learned songs). It does
not unlock songs or events.

## Download and install

1. You need **TriAevum (OoT3D, Windows)** installed and working, with your own game data generated by it (the
   `PC-OoT3D\Jogo` folder with `data\`, `private-plugins\`, `resources\` and your save).
2. Download `Ocarina-Microfone-PC-v0.6.0.zip` from the
   [Releases](../../releases) page and extract it, then copy the folder's contents **over your `PC-OoT3D` folder** (see the layout in
   [README.pt-BR.md](README.pt-BR.md) or the `LEIA-ME.md` inside the zip).
3. Run `INICIAR_COM_MICROFONE.cmd`, press **Esc** in game and pick your microphone, take out the ocarina and play.

The launcher generates `Jogo\ModMicrofone\Microfone.launch.json` from a template pointing at *your* install; it
does not touch the original game launcher. The mod uses the save folder `Jogo\data\savedata-microfone` (a copy of
your save), so back up your saves.

The exe is a build of TriAevum with this mod applied; the original TriAevum is not modified. See
[Legal / licensing](#legal--licensing).

## The 12 songs

(Note names: D4 is the low D of the ocarina, D5 an octave above.)

| Song | Notes |
|---|---|
| Zelda's Lullaby | B4 D5 A4 · B4 D5 A4 |
| Epona's Song | D5 B4 A4 · D5 B4 A4 |
| Saria's Song | F4 A4 B4 · F4 A4 B4 |
| Sun's Song | A4 F4 D5 · A4 F4 D5 |
| Song of Time | A4 D4 F4 · A4 D4 F4 |
| Song of Storms | D4 F4 D5 · D4 F4 D5 |
| Minuet of Forest | D4 D5 B4 A4 B4 A4 |
| Bolero of Fire | F4 D4 F4 D4 A4 F4 A4 F4 |
| Serenade of Water | D4 F4 A4 A4 B4 |
| Requiem of Spirit | D4 F4 D4 A4 F4 D4 |
| Nocturne of Shadow | B4 A4 A4 D4 B4 A4 F4 |
| Prelude of Light | D5 A4 D5 A4 B4 D5 |

Tips: repeated equal notes need a small pause between them; stay silent for a moment after finishing the phrase so
the last note is closed; the scarecrow's custom song is not included. Pressing a music command by hand cancels
listening until the ocarina is closed and opened again.

## How it works

The mod lives in the TriAevum host (the C++ runtime that runs the recompiled game) and talks to the game through
its **native state**, so the same mechanism is portable to other platforms (the 3DS plugin reuses it).

- **Capture** — WASAPI shared-mode capture (`wasapi_capture.cpp`) feeds a pitch detector (`pitch_detector.cpp`;
  autocorrelation with a loudness gate and octave handling, whistles analysed up to 4 kHz). `mic_controller.cpp`
  owns the capture, switches devices at runtime and falls back to the Windows default if a device disappears;
  `mic_settings.cpp` holds the pure logic (saved choice by endpoint ID/name, priority
  `TRIAEVUM_OCARINA_MIC_DEVICE` > saved choice > Windows default).
- **Notes and matching** — `note_tracker.cpp` turns pitch frames into notes (hysteresis, short pauses separate
  repeated notes); `song_matcher.cpp` compares the interval shape against `song_catalog.cpp` in an *assisted* mode
  (loose tolerance) and reports a song, an ambiguity or nothing.
- **Playing the song** — `game_input.cpp` replays the song as the game's own button presses
  (L, R, Y, X, A) into the emulated HID state, with a 1.5 s delay (`TRIAEVUM_OCARINA_REPLAY_DELAY`), so the game
  itself recognises it.
- **Native confirmation box** — `oot3d_ocarina_dialog_runtime.*` opens the game's message system (message
  context state machine, the message loader, UTF-8 text with `7F` control codes for choices) **without** the
  `StartTextbox` function (it closes the ocarina page), saves/restores the part of the message context that
  holds the ocarina session, reads the highlighted option and cancels safely on timeout. The full sequence,
  addresses and pitfalls are in [`docs/NATIVE_DIALOG.md`](docs/NATIVE_DIALOG.md).
- **Esc menu tab** — `oot3d_ocarina_microphone_menu.*` adds the "Microfone da Ocarina" tab to the game's own
  in-game menu (`oot3d_in_game_menu.*`).
- More detail in [`docs/INTEGRATION.md`](docs/INTEGRATION.md) and `source/tools/real_instrument/README.md`.

Environment variables (set by the launcher): `TRIAEVUM_OCARINA_MIC=1` enables the mod,
`TRIAEVUM_OCARINA_NATIVE_DIALOG=1` uses the native Yes/No box, `TRIAEVUM_OCARINA_MIC_DEVICE=<n>` forces a device,
`TRIAEVUM_OCARINA_REPLAY_DELAY=<s>`.

## Source code and building

```
source/            files of this mod, at the same paths as in the TriAevum tree
  tools/real_instrument/                         detector, matcher, capture, device settings, tests
  tools/oot3d/native_game_runtime/oot3d_ocarina_* new files (dialog runtime, mic menu)
  tools/oot3d/native_game_runtime/*  CMake/oot3d/game.cmake   modified TriAevum files
patches/ocarina-microphone.patch   the same changes as one `git apply`-able patch
docs/                              mechanism documentation
launcher/                          the launcher script and launch-profile template used in the release zip
```

Built against upstream TriAevum commit **`8f69a26f390bf3a500bf3149b6596c19724a5b5d`**
(`https://github.com/coccofresco/TriAevum`). To rebuild:

```sh
git clone https://github.com/coccofresco/TriAevum && cd TriAevum
git checkout 8f69a26f390bf3a500bf3149b6596c19724a5b5d
git apply --whitespace=nowarn /path/to/ocarina-microphone.patch
# then build the oot3d_native_game target as the TriAevum documentation describes
```

The distributed exe was built on Windows with clang-cl (Ninja, MSVC runtime) with the optional iMMERSE and DLSS modules **off**.
The pure-logic tests of the mod build and run on their own:

```sh
cmake -S source/tools/real_instrument -B build-recognition -G "Visual Studio 17 2022" -A x64
cmake --build build-recognition --config Release
ctest --test-dir build-recognition -C Release --output-on-failure
```

## Troubleshooting

- *Level bar stuck / no notes*: check **Ativar microfone** and the device in the Esc tab; allow desktop apps to
  use the microphone in Windows settings; make sure no other program holds it exclusively.
- *Chosen microphone went back to the Windows default*: it was unplugged or failed to open; reconnect and press
  **Atualizar lista**.
- *Reset the setting*: with the game closed, delete `Jogo\data\config\ocarina_microfone.json`.
- `ferramentas\OcarinaMicrofone.exe --choose` shows the heard notes and recognised song without controlling the
  game; `--list-devices` lists microphones.
